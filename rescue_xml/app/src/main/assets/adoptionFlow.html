领养流程说明

先申请，再沟通；实际接宠后，由送养人确认完成送养。

从发布到接宠

  1. ① 送养人发布帖子填写宠物介绍、图片、地区与联系方式
  2. ② 领养人提交申请登录 → 填写或复用领养资料 → 阅读领养须知 → 继续申请；首次保存资料返回后需再次点击申请
  3. ③ 送养人审核申请在「消息 → 收到的申请」中查看申请人及其提交申请时的资料
  4. ④ 同意沟通，开放联系方式领养人在「消息 → 我的申请」中查看、复制联系方式
  5. ⑤ 双方沟通，确认实际接宠确认宠物情况、领养条件与交接安排
  6. ⑥ 送养人确认完成送养选择实际接宠的沟通中申请 → 完成送养 → 整帖结束，其他有效申请自动结束

送养人怎么操作

发布信息，等待申请

填写真实、清楚的宠物信息，并留下方便联系的手机号或微信。联系方式不会因为发布帖子就向申请人开放，需要你先同意沟通。

审核申请，决定是否沟通

进入「消息 → 收到的申请」，查看申请人及其提交申请时的领养资料。申请中可选择「同意沟通」或「拒绝申请」。确认同意沟通后，申请人会收到提醒，并可以查看该帖预留的联系方式；拒绝后，对方的申请显示为「被拒绝」。

实际接宠后，确认完成送养

沟通中的申请可选择「结束沟通」或「完成送养」。请在宠物已实际交接后，对实际接宠人的申请点击「完成送养」并确认。帖子将结束，其他进行中的申请也会自动结束，联系方式授权撤销。

「同意沟通」只是开放联系，不表示已完成领养。「结束沟通」只结束这一份申请，不表示整帖已送养。

领养人怎么操作

填写资料，阅读须知后申请

在送养帖子详情点击「申请领养」。未登录时先登录；没有领养资料时，按提示去填写资料，保存并返回详情后，再次点击申请。阅读领养须知并点击「继续申请」，提交成功后等待送养人反馈。

查看进展，联系送养人

进入「消息 → 我的申请」查看状态。申请中等待审核；进入沟通中后，可查看并复制送养人的联系方式，与对方确认宠物情况和交接安排。

有变化时，及时结束申请

如果不再考虑领养，可点击「放弃申请」并确认。放弃、被拒绝或结束沟通，都只代表这份申请结束；帖子是否仍在送养，以详情页的状态为准。

怎样区分几种状态

申请中
申请已提交，等待送养人处理，尚未开放联系方式。

沟通中
送养人已同意沟通，申请人可以查看联系方式，双方继续确认是否适合领养。

已结束 / 被拒绝
这份申请已结束，不代表宠物一定已被领养，也不一定影响其他人的申请。

送养已结束
整条帖子已完成送养或被送养人关闭，不再接受新的申请。

如果暂时不再送养

送养人可从本人帖子详情右上角的管理菜单选择「关闭送养」。关闭会结束整帖的有效申请并停止显示联系方式，表示未完成送养，与选择实际接宠人后「完成送养」不同。

交接前的小提醒

  • 如实说明宠物健康、性格和照护需要，认真了解彼此的领养条件。
  • 沟通中也可以结束申请，不必为了已经联系而勉强交接。
  • 交接前确认双方身份与宠物情况，警惕以押金、定金等理由要求转账。
  • 实际接宠后再确认完成送养，避免提前结束帖子。
